# lambdatest_cypress10
A basic sample code for Cypress 10 setup on LambdaTest.

Steps:
1) Clone/download the repo.
2) Run the following command to install dependencies>
3) npm install -g lambdatest-cypress-cli
4) npm i
5) lambdatest-cypress init --cv=10
6) Set LambdaTest username and access key in lambdatest-config.json (OR, set LT_USERNAME and LT_ACCESS_KEY in environment variables)
7) run the command> lambdatest-cypress run
