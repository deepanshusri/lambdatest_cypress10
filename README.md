# lambdatest_cypress10
A basic sample code for Cypress 10 setup on LambdaTest.

Steps:
1) Clone/download the repo.
2) Run the following command to install dependencies>

npm install -g lambdatest-cypress-cli
npm i
lambdatest-cypress init --cv=10

4) Set LambdaTest username and access key in lambdatest-config.json (OR, set LT_USERNAME and LT_ACCESS_KEY in environment variables)
5) run the command> lambdatest-cypress run
